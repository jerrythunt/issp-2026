# ISSP 2026
## BCIT and LeBlanc Leadership Group

A web application for building a 360 self assessment tool.

## Overview
ISSP 2026 is a front end web app designed to support a 360 feedback and self assessment experience.
Users can complete assessments, review results, and track growth over time.

## Features
- 360 self assessment workflow
- Responsive user interface
- Results and reporting views
